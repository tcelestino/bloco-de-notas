### Modificado

- Novo visual minimalista, em coluna única, com a fonte IBM Plex Sans (carregada do Google Fonts)
  - Tema claro e escuro automático, de acordo com a preferência do sistema
  - Cabeçalho com Posts e Changelog; redes sociais e RSS foram para o rodapé
  - Lista de posts com data e título, agrupada por ano na página de todos os posts
  - Cores de marca das redes sociais e botão colorido removidos, com um único acento roxo nos links
- Botão com ícones de lua e sol no menu do cabeçalho para alternar o tema manualmente (nome acessível "Modo escuro")
  - A escolha fica salva no navegador (`localStorage`); sem escolha, vale o tema do sistema
  - Script mínimo inline em `src/_includes/theme.js`, aplicado antes da pintura para evitar flash de tema errado
  - O botão só aparece com JavaScript ativo
- Acessibilidade
  - Link para pular para o conteúdo, foco visível em todos os links e menu com `aria-current`
  - Contraste mínimo AA nos temas claro e escuro, inclusive no destaque de código
  - Um `h1` por página, blocos de código rolam e recebem foco por teclado
- Blog migrado do GitHub Pages para o Cloudflare
  - Novo endereço: `https://blog.tcelestino.dev.br/`
  - Deploy continua automático via GitHub Actions a cada merge na `main`, agora com `wrangler deploy`
  - Removido `--pathprefix=bloco-de-notas` do script `build`
  - URLs de `src/_data/site.json`, `src/feed.njk` e links internos dos posts atualizadas para o novo domínio

### Adicionado

- `wrangler.jsonc` com a configuração do Worker de assets estáticos e do custom domain
- Redirecionamento do endereço antigo do GitHub Pages para `https://blog.tcelestino.dev.br/`
  - Stub em `redirect-stub/` publicado na branch `gh-pages` por `.github/workflows/redirect-stub.yml`
  - Feed antigo agora avisa da mudança de endereço
- Preview deploy por Pull Request
  - Workflow `.github/workflows/preview.yml` sobe uma versão do Worker com alias `pr-<número>` e comenta a URL no PR
  - `wrangler.jsonc` com `preview_urls: true` e `workers_dev: false`
